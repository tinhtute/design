# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Frontend developers and product teams building modern web applications who need accessible, production-ready design system primitives installable via shadcn CLI.

## Product Purpose

Deliver an accessible, high-craft shadcn/ui registry and design system (`@therealtinhtute/design`) based on Kumo's component catalog with custom `#124b68` brand aesthetics and zero runtime vendor dependencies.

## Positioning

The only source-code-first shadcn registry porting Kumo's enterprise-grade Base UI + Hugeicons component catalog with a customizable tokenized theme system.

## Operating Context

Developers install components via `pnpm dlx shadcn add @therealtinhtute/{component}` directly into their source tree. The showroom app allows interactive preview and testing of all components, charts, and patterns.

## Capabilities and Constraints

- 53 catalog items (44 UI components, 3 blocks, 3 patterns, 3 infra items).
- Base UI primitives + Hugeicons icons.
- Strict WCAG 2.1 AA accessibility compliance.
- No `@cloudflare/kumo` runtime dependency for consumers.
- Primary brand color: `#124b68` (`oklch(0.3917 0.0748 236.055)`).

## Brand Commitments

- Name: `@therealtinhtute/design` / `mono`
- Brand accent: `#124b68` deep ocean blue
- Neutral foundation with accessible light/dark mode contrast

## Product Principles

1. Source-code first: consumers own the component code, zero vendor lock-in.
2. Accessibility without compromise: keyboard navigation, screen reader affordances, visible focus rings.
3. Strict craftsmanship: precise alignment, fluid layout, purposeful motion, zero tacky animations.
